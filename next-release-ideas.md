# Next release: ideas

A working list for v8. Write freely here. When a release ships, move what made it into `changelog.html` and clear the list.

Each idea gets a size: **S** is an afternoon, **M** a day or two, **L** more than that.

## Feel

- **S:** a reading lamp that only switches on at night (India time). It warms the shelves without adding another object to tap.
- **S:** the brooch catches light once when you scroll past the top rail, not only on a timer.
- **M:** dust settles on books nobody has borrowed for a long time, and taking one out blows it off.
- **M:** a page-turn sound recorded from a real book, replacing the synthesised one if it sounds better.

## Personal

- **M:** a “Lately” note on the plaque’s back: the last book Abhijeet added, in his words.
- **M:** letters in the margins. A short handwritten note on a few favourite cards, in a script face.
- **S:** the plant grows a new leaf on the first watering of each month, instead of on a count.

## Finding things

- **M:** “More like this” on a card, from the search engine’s nearest neighbours, shown as three small spines.
- **S:** Wander remembers the last few books it chose, so it doesn’t repeat them.
- **L:** search across what the linked pages actually say (descriptions fetched at build time).

## The extension

- **S:** remember the last shelf used, and suggest it when the page looks similar.
- **M:** add several open tabs at once, from a short list with tick boxes.
- **M:** a small badge on the toolbar icon when the page you are on is already in the library.

## Housekeeping

- **S:** a weekly check that marks books whose sites have moved, and offers the archived copy.
- **S:** an “Export everything” button in the admin panel (JSON and a plain HTML list).
- **M:** a longer admin passcode, or a passkey, before the site is shared widely.

## Not doing (and why)

- Accounts, likes and comments: this is one person’s library, not a feed.
- Analytics beyond the plant’s count: nothing tracks visitors.
